# 📟 Módulo Terminal RPG (`terminal_rpg`)

O diretório `terminal_rpg` contém o protótipo autônomo original do RPG em modo texto de terminal. Ele funciona como uma versão independente, ideal para testes rápidos de prompts e interação direta via linha de comando.

---

## 📂 Arquivos do Módulo

- **`rpg.py`**: Script executável do RPG com integração direta com a biblioteca `google-generativeai`.
- **`run.sh`**: Script bash de inicialização rápida do jogo no terminal.
- **`check_env.sh`**: Script para validação de ambiente Python e variáveis de configuração.
- **`install_dependencies.sh`**: Script de automação para instalação das dependências específicas desta versão.
- **`requirements.txt`**: Lista de pacotes necessários para executar esta versão isolada.

---

## 🚀 Como Executar

```bash
cd terminal_rpg
./run.sh
```
Ou diretamente:
```bash
python terminal_rpg/rpg.py
```
